Thread and GPU computing

The $1/hour fee covers the basic computing cost of running one AI thread. Projects that require substantial GPU computing power for model development will need to cover the additional fees.

Executive51 is set up to use Azure. You will not be charged a premium on top of Azure's fees, but you will need to cover the cost of Executive51 setting up your project. Setup should be inexpensive: Executive51 should be able to complete it within an hour or two.

Prices for a GPU-enabled machine on Azure start at less than a dollar. Other compute arrangements are possible; feel free to inquire.
