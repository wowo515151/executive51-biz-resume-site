Available graphs

  • Foods in the Canadian Nutrient File

    Browse the food descriptions maintained in Health Canada's Canadian Nutrient File, a reference database for foods commonly consumed in Canada. Each record supplies a food code and food name, which can help identify the entries used in the nutrient resources. Use the official guide to review the database scope and field definitions before interpreting food codes.

  • Nutrient names and units

    Explore the nutrient names and units defined by the Canadian Nutrient File. The records include identifiers, display names, units, and grouping fields used to describe nutrient measurements across foods. Consult Health Canada's API guide for the field definitions and notes about how nutrient names are presented.

  • Nutrient amounts in Gouda cheese

    Review the nutrient measurements recorded for the Canadian Nutrient File's Gouda cheese example (food code 109). The API guide describes these values per 100 grams of edible portion and includes the nutrient name, value, unit context, and supporting observation fields. This reference composition is not a personalized dietary recommendation; check Health Canada's notes when comparing individual nutrient values.
